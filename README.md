# Sales & Revenue Analysis Dashboard

## Overview

An interactive Sales & Revenue Analysis Dashboard developed using Microsoft Power BI to analyze business sales performance and generate useful insights.

## Key Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Order Value
- Sales trend by year
- Sales analysis by category
- Sales analysis by region
- Top 5 products by sales
- Category filter
- Region filter
- Order date filter

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
- Data Visualization

## Dataset

The dashboard uses the Superstore sales dataset containing order, customer, product, sales, profit, category, region, and date information.

## Dashboard

The Power BI dashboard provides an interactive view of sales and revenue performance through KPI cards, charts, and slicers.

## Project Purpose

This project was created as part of a Data Analytics Internship task to demonstrate skills in data importing, data visualization, KPI tracking, interactive filtering, and business insight generation.
